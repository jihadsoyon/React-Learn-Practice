# 🩸 BloodFinder

A modern and responsive blood donation web application built with **React, Tailwind CSS, and DaisyUI**.  
BloodFinder helps users instantly find compatible blood donors using smart filtering, blood matching, and emergency request systems.

---

# 🚀 Live Demo

🔗 https://blood-fiinder.netlify.app/

---

# ✨ Features

## 🔥 Core Features

- Blood donor registration system
- Real-time donor search & filtering
- Blood group compatibility matching
- Emergency blood request system
- Dynamic donor availability tracking
- Responsive modern UI
- Smooth scrolling navigation
- Interactive healthcare dashboard

---

## 🎯 Advanced Features

- AI-style donor matching section
- Smart donor filtering by:
  - Blood Group
  - Division
  - Availability
- Emergency donor request alerts
- Dynamic donor database rendering
- Animated hero/banner section
- Professional sticky navbar
- Modern glassmorphism UI
- Fully responsive design

---

# 🧠 Blood Compatibility System

The application includes a blood compatibility engine that helps users instantly identify compatible donors based on selected blood groups.

Example:

| Blood Group | Compatible Donors |
|---|---|
| A+ | A+, A-, O+, O- |
| O- | O- |
| AB+ | All Blood Groups |

# ⚙️ Installation & Setup

## Clone the repository

```bash
git clone https://github.com/your-username/bloodfinder.git
```

---

## Navigate to the project folder

```bash
cd bloodfinder
```

---

## Install dependencies

```bash
npm install
```

---

## Run the development server

```bash
npm run dev
```
