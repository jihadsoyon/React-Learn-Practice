# 📚 What I Learned — Tailwind CSS & React

This section documents the concepts, tools, and practical skills I learned while working with **Tailwind CSS, DaisyUI, and React**.

## 🚀 Topics Covered

### 🎨 Tailwind CSS & DaisyUI

* Set up **Tailwind CSS** and **DaisyUI** with a Vite + React application.
* Learned how to use DaisyUI's pre-built components.
* Customized DaisyUI components to match the application's design.
* Built and modified **pricing cards** using DaisyUI.

### 🧭 Navigation & Icons

* Created a custom responsive navigation bar.
* Integrated **Lucide React** for modern and reusable icons.
* Learned how to structure navigation components in React.

### 🔄 Dynamic Menus & State Management

* Implemented dynamic menu buttons.
* Built toggle functionality for navigation menus.
* Created interactive menu items using React state.
* Practiced conditional rendering based on component state.

### 💰 Pricing Data & Components

* Created structured pricing data.
* Rendered pricing plans dynamically using React.
* Reused components to display multiple pricing options.
* Practiced separating data from UI components.

### 📊 Data Processing & Charts

* Explored **Axios** for handling API requests.
* Learned the basics of processing API/chart data.
* Worked with bar charts to visualize data.
* Practiced transforming raw data into chart-friendly formats.

### 🧩 React Component Libraries

* Explored **React Awesome Components** and reusable React UI components.
* Learned how component libraries can speed up development while maintaining consistency.

## 🛠️ Technologies & Tools

* React.js
* Vite
* Tailwind CSS
* DaisyUI
* Lucide React
* Axios
* React Charting / Bar Charts
* React Component Libraries

Through this part, I strengthened my understanding of:
