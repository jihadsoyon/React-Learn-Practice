# 🚀 Kanban Search & Filter

A modern React-based Kanban task management interface with real-time search and status filtering functionality.
This project demonstrates clean state management, reusable component architecture, and instant UI updates.

---

## 🧩 Problem This Project Solves

Managing tasks becomes difficult when there are too many items in different stages.
This project helps users:

* Quickly search tasks
* Filter tasks by status
* Instantly view relevant tasks
* Improve productivity with organized workflow

---

## ✨ Features

* 🔍 Real-time task search
* 🎯 Filter tasks by status
* ⚡ Instant UI updates
* 🧠 Derived state optimization
* ♻️ Reusable React components
* 📱 Responsive modern UI

---

## 🛠️ Tech Stack

* React
* JavaScript (ES6+)
* CSS3
* Vite
