# 📸 Image Upload Preview App

A modern React application that allows users to upload images, instantly preview them, and remove selected images before upload.
This project demonstrates practical frontend development skills including **FileReader API usage, state management, conditional rendering, and responsive UI design**.

---

# 🚀 Features

* 📂 Upload image files
* ⚡ Instant image preview
* ❌ Remove uploaded image
* 🎨 Modern responsive UI
* 🧠 Built with React Hooks
* 📱 Mobile-friendly layout

---

# 🛠️ Tech Stack

* React (Vite)
* JavaScript (ES6+)
* CSS3
* FileReader API


# 🎯 How It Works

1. Select an image from your device
2. The app reads the file using the FileReader API
3. A live preview is displayed instantly
4. Users can remove the selected image anytime
