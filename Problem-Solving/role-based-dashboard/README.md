# 🚀 Role-Based Protected Dashboard

A modern React application demonstrating Authentication, Protected Routes, and Role-Based Access Control (RBAC). This project showcases how different user roles can access different parts of an application while maintaining a secure and scalable architecture.

---

## 📌 Problems Solved

This project addresses several real-world frontend challenges:

- Restricting unauthorized users from accessing protected pages
- Implementing role-based access control (Admin vs User)
- Managing authentication state across the application
- Conditionally rendering UI based on user permissions
- Creating a scalable route protection system
- Handling unauthorized access gracefully

---

## ✨ Features

### 🔐 Authentication System
- Login as Admin
- Login as User
- Logout functionality

### 🛡️ Protected Routes
- Authenticated users can access dashboard routes
- Unauthenticated users are redirected to login

### 👥 Role-Based Access Control (RBAC)
- Admin-only routes
- User-specific dashboard experience
- Conditional navigation links
