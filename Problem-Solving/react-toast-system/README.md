# 🔔 Custom Toast Notification System

A modern and reusable **Toast Notification System** built with React.
This project demonstrates **global state management, reusable UI components, auto-dismiss notifications, and smooth user interactions**.

---

## ✨ Features

* ✅ Success & Error toast notifications
* ⏱️ Auto dismiss functionality
* 📦 Multiple toast support
* 🌍 Global notification management using Context API
* 🎨 Clean and responsive UI
* ⚡ Smooth slide-in animation

---

## 🛠️ Tech Stack

* React (Vite)
* JavaScript (ES6+)
* CSS3
* React Context API

## 🚀 How It Works

* Click the buttons to trigger toast notifications
* Notifications automatically disappear after 3 seconds
* Multiple toasts can appear simultaneously
* State is managed globally using React Context API

---

## 🧠 Challenges Faced

* Managing global notification state
* Supporting multiple simultaneous toasts
* Implementing auto-dismiss functionality cleanly
* Creating reusable and scalable components
