# 🔐 Authentication UI Flow

A modern authentication UI project built with React featuring login and registration forms with reusable components and validation.

---

## 🚀 Problems Solved By This Project

- Form validation handling
- Password show/hide functionality
- Reusable input component architecture
- Managing authentication form state
- Clean UI structure for authentication flow

---

## ✨ Features

- Login form
- Register form
- Password visibility toggle
- Validation handling
- Reusable input fields
- Responsive UI design
