# 🌗 Theme Switcher App

A modern React application that allows users to switch between **Light Mode** and **Dark Mode** with smooth transitions and persistent theme saving using `localStorage`.

---

## 🚀 Features

* 🌞 Light Mode
* 🌙 Dark Mode
* 🔄 Smooth theme transition
* 💾 Theme persistence using localStorage
* ⚛️ Global theme management with Context API
* 🧩 Reusable component structure
* 📱 Responsive UI

---

## 🛠️ Tech Stack

* React (Vite)
* JavaScript (ES6+)
* Context API
* CSS3
* LocalStorage

```bash id="2gwy0f"

cd theme-switcher

```

---

## 🎯 How It Works

* The application uses React Context API for global theme state management.
* Theme preference is stored in `localStorage`.
* On page reload, the previously selected theme remains active.
* Smooth transitions are applied using CSS animations.
