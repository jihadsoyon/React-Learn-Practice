# 📄 React Pagination System

A modern and responsive **React Pagination System** built with React and Vite.
This project demonstrates API fetching, dynamic pagination, reusable components, and async state management.

---

## 🚀 Features

* ✅ Fetch data from API
* 📄 Dynamic pagination system
* ⏮️ Previous / Next navigation
* 🔢 Dynamic page numbers
* ⚡ Fast and responsive UI
* ♻️ Reusable pagination component
* 🎯 Component-based architecture

---

## 🛠️ Tech Stack

* React.js
* Vite
* JavaScript (ES6+)
* CSS3
* JSONPlaceholder API
