# 🚀 Mini Trello Board (Drag & Drop Task Manager)

A modern and interactive **Trello-inspired task management app** built with React.
This project demonstrates advanced **drag-and-drop functionality, state management, and clean UI design**.

---

## ✨ Features

* ✅ Drag & Drop tasks between columns
* 🔄 Reorder tasks within the same column
* 📦 Move tasks across different columns
* ⚡ Smooth and responsive UI interactions
* 🧠 State management using React Hooks
* 🎯 Component-based architecture

---

## 🛠️ Tech Stack

* React (Vite)
* JavaScript (ES6+)
* CSS (Custom styling)
* @hello-pangea/dnd (Drag & Drop library)

---

## ⚙️ Installation & Setup

Clone the repository and install dependencies:

```bash
git clone https://github.com/jihadsoyon/React-Learn-Practice.git
cd React-Learn-Practice/Problem-Solving/mini-trello-board
npm install
npm run dev
```

## 🎮 How It Works

* Drag a card to reorder within the same column
* Drag across columns to change task status
* UI updates instantly using React state
