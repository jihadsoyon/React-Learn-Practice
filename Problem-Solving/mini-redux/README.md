# Mini Redux - Global State Manager

A scalable React global state management project built using Context API and useReducer.

---

## Features

- Global Theme State
- Global Cart State
- Global User State
- Add to Cart
- Remove from Cart
- Dark / Light Mode
- Reusable Architecture
- Centralized Reducer Logic

---

## Problems Solved By This Project

- Prop Drilling Problem
- Scalable State Management
- Shared Global Data Handling
- Reducer-Based State Updates
- Clean Component Communication
