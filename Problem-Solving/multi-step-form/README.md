# Multi-Step Form Wizard

A modern and responsive **Multi-Step Form Wizard** built with React.
This project demonstrates advanced **form state management, validation, localStorage persistence, and reusable component architecture**.

---

# Features

* ✅ Multi-step form navigation
* 👤 Personal Information step
* 🌍 Address Information step
* 📋 Review & Submit section
* ⏮️ Next / Previous navigation
* ⚠️ Form validation
* 💾 Data persistence using localStorage
* 📊 Dynamic progress bar
* 🎨 Clean and modern UI

---

# Tech Stack

* React (Vite)
* JavaScript (ES6+)
* CSS3
* React Hooks (`useState`, `useEffect`)

# ⚙️ Installation & Setup

Clone the repository and install dependencies:

```bash id="sflvg9"
git clone https://github.com/jihadsoyon/React-Learn-Practice.git

cd React-Learn-Practice/Problem-Solving/multi-step-form

npm install

npm run dev
```
